# 🏛️ ระบบบริหารจัดการและบริการลูกค้า โรงงานฝาทรงไทยเมืองเพชร

> **Management and Customer Service System for Phetchaburi Thai Traditional Woodwork Factory**

เว็บแอปพลิเคชันสำหรับนำเสนอผลงาน ให้บริการลูกค้า และช่วยบริหารจัดการข้อมูลภายใน **โรงงานฝาทรงไทยเมืองเพชร** โดยออกแบบให้ครอบคลุมทั้งฝั่งลูกค้า (Customer Front-end) และระบบบริหารจัดการหลังบ้าน (Admin Management System)

โปรเจกต์นี้พัฒนาด้วย **Next.js 14 (App Router), React, TypeScript, Tailwind CSS, Supabase และ PostgreSQL** พร้อมฟังก์ชันสำคัญ เช่น แคตตาล็อกผลงาน ระบบประเมินราคา แผนที่ผลงาน ระบบติดตามลูกค้า ระบบตารางงาน ระบบสต็อก และแชทบอทภาษาไทย “น้องไทยบอท”

> 🎓 **Portfolio Project** — โปรเจกต์นี้จัดทำขึ้นเพื่อการศึกษาและใช้เป็นผลงานด้าน Web & App Development ของผู้พัฒนา

## 👩‍💻 About This Project

โปรเจกต์นี้เกิดจากแนวคิดในการนำเทคโนโลยีเว็บมาประยุกต์ใช้กับธุรกิจงานไม้สถาปัตยกรรมไทย เพื่อช่วยให้การนำเสนอผลงาน การให้ข้อมูลลูกค้า และการจัดการข้อมูลภายในโรงงานสามารถทำได้ผ่านระบบเดียว

ตัวระบบถูกออกแบบให้มี 2 ส่วนหลัก ได้แก่

1. **Customer Front-end** — สำหรับลูกค้าที่ต้องการดูผลงาน ประเมินราคางานเบื้องต้น ดูตำแหน่งผลงาน ตารางคิว และติดต่อโรงงาน
2. **Admin Management System** — สำหรับผู้ดูแลระบบในการจัดการลูกค้า ผลงาน ข่าวสาร ตารางงาน สต็อก การตั้งค่าราคา และข้อมูลแชทบอท

โปรเจกต์นี้ยังถูกพัฒนาเพื่อฝึกและแสดงทักษะด้าน **Web Application Development, UI/UX Design, Database Management, System Design และการออกแบบระบบให้ตอบโจทย์การใช้งานจริง**

> **หมายเหตุ:** Repository นี้จัดทำขึ้นเพื่อใช้เป็น Portfolio และเพื่อการศึกษา ข้อมูลบางส่วนภายในระบบอาจเป็นข้อมูลตัวอย่างหรือข้อมูลที่ใช้เพื่อสาธิตการทำงานของระบบ และไม่ควรถือว่าเป็นเว็บไซต์ทางการของโรงงาน

## 🌟 Key Features

### 🌐 1. ระบบฝั่งลูกค้า (Customer Front-end)

#### Hero & Artisan Storytelling

- แสดงวิดีโอบรรยากาศงานช่างไม้เมืองเพชรบุรี
- ถ่ายทอดเอกลักษณ์งานฝาทรงไทยและงานไม้แบบดั้งเดิม
- มีปุ่มสำหรับติดต่อโรงงานได้อย่างรวดเร็ว

#### Interactive Woodwork Estimator (`/estimator`)

- ระบบประเมินงบประมาณงานไม้แบบเรียลไทม์
- รองรับงาน เช่น หน้าจั่วทรงไทย ประตูแกะสลัก วงกบ ฝาปะกน และศาลา
- เลือกเกรดไม้และระดับรายละเอียดของงานได้
- คำนวณช่วงราคาประเมินต่ำสุด–สูงสุด
- สามารถส่งรายละเอียดที่เลือกไว้เพื่อนำไปใช้ในการสอบถามราคาเพิ่มเติม

#### Masterpiece Portfolio & Lightbox

- แคตตาล็อกผลงานแบ่งตามหมวดหมู่
- รองรับการค้นหาผลงาน
- เปิดดูรายละเอียดและอัลบั้มภาพผ่าน Lightbox
- รองรับภาพผลงานหลายรูปต่อหนึ่งโปรเจกต์

#### Factory Feed & Updates

- แสดงข่าวสารและอัปเดตผลงานของโรงงาน
- รองรับรูปภาพ วิดีโอ และ Facebook Embed
- รองรับการกดไลก์และการปักหมุดโพสต์สำคัญ

#### Interactive Map of Thailand

- แสดงตำแหน่งผลงานที่ติดตั้งในพื้นที่ต่าง ๆ
- รองรับการกรองตามภูมิภาค
- แสดงข้อมูล รูปภาพ และพิกัดของผลงาน
- สามารถเปิดตำแหน่งต่อใน Google Maps ได้

#### Public Production Schedule

- แสดงตารางคิวงานที่กำลังดำเนินการ
- แสดงช่วงเวลาที่มีคิวงานและช่วงที่สามารถรับงานใหม่ได้
- ช่วยให้ลูกค้าเห็นภาพรวมสถานะงานได้สะดวกขึ้น

#### Smart Thai Chatbot — “น้องไทยบอท”

- ระบบแชทบอทภาษาไทยสำหรับตอบคำถามที่พบบ่อย
- ใช้ Rule-based / Thai NLP Pattern Matching ในการจับคู่ข้อความ
- รองรับคำถามเกี่ยวกับที่ตั้ง ราคา การใช้ไม้ การสั่งทำ และข้อมูลทั่วไป
- มี Quick Actions เช่น เปิดแผนที่ เปิดหน้าประเมินราคา และติดต่อโรงงาน
- มีแบบฟอร์มฝากข้อมูลลูกค้าเพื่อส่งเข้าสู่ระบบ CRM

#### Floating Quick Actions

- ปุ่มลอยสำหรับติดต่อโรงงาน
- ปุ่มเปิดแชทบอทจากหน้าต่าง ๆ ของเว็บไซต์

## 🗄️ Supabase Setup

ระบบรองรับการเชื่อมต่อกับ **Supabase PostgreSQL** และมี Hybrid Data Store สำหรับจัดการข้อมูลระหว่าง Local Storage และฐานข้อมูล

### ขั้นตอนการตั้งค่า

1. สร้างโปรเจกต์ใหม่ใน Supabase
2. เปิดเมนู **SQL Editor**
3. นำ SQL จากไฟล์ด้านล่างไปรัน

```text
supabase/schema.sql
```

4. สร้างไฟล์ `.env.local` ในโฟลเดอร์หลักของโปรเจกต์

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anon-key
```

5. Restart Development Server

```bash
npm run dev
```
